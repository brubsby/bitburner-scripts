THE PASS CONDITION, FROM SOURCE. With no white stone on the board, getMove passes iff every move generator is empty:
no available point (white's valid moves minus every empty region of <= min(0.4 x nodes, 11) points touching only
black: controlledTerritory.ts:24-82, boardAnalysis.ts:282-314) is an expansion point (4 empty neighbours) or a
surround/atari/capture liberty (goAI.ts:628-711), and every 3x3 corner box with >= 7 live nodes holds a stone
(goAI.ts:443-481). Patterns need a white stone; growth/defend/eyeMove need white chains; eyeBlock is not modelled
and is caught by the getMove verification. S_min per DEALT layout (offline nodes; Illuminati's handicap router
captured) = the fewest stones meeting it, found by simulated annealing on that model, every set VERIFIED against
the game's own getMove on 64 seeds (+ full black score). Checks of the optimiser: on 5x5 the annealer hits the
EXHAUSTIVE minimum on every layout tried, and 5x5 S_min is exhaustive (47 of 48 layouts exact, one 4-5); a 6x longer anneal
moves 9x9 (4 layouts) and 7x7 (6) by 0 stones, 13x13 (3) by -0.7 (-1.5%). The getMove-checked greedy behind the old
table (go-passmin.mjs) was 25-40% above these on 7x7-13x13 (empty boards: 5/16/26/57 -> 4/12/21/48).

CHEAT SCHEDULE. chance(k) = min(1, 0.6 (0.7-0.02k)^k crime + 0.25[SF14.3]); go-cheat.js plays only inside the
clock window roll <= chance(k) (the roll is ONE 59.06s sawtooth rising 0.0169/s, so availability is a function
of the game's start phase, integrated over 2000 phases, not an independent draw per turn; waits <= 0.5s), greedy
(optimal: chance falls with k, the roll rises), maxPerGame 12. R = AI replies incl. its final pass; ours = 0.
power/h = 3600 x 3 (streak) x difficulty x area / AI-seconds, AI-seconds = (R-1) x reply + pass, reply = the
game's 200c+10r timer model (go-turntime.mjs, 0.7% vs live) on prefixes of the final structure.
Other cheats, not searched (argued): each costs a whole reply AND a cheat count (lowering playTwoMoves' odds).
destroyNode makes a wall that scores nothing (an offline node does avoid the surround constraint a stone carries,
but playTwoMoves at the same count places two scoring walls); repairOfflineNode buys 1 point for a reply where
every board here earns 4-11; removeRouter has no target (no white stone) except Illuminati's handicap router,
which the structure captures with stones that also score.
